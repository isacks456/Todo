Приложение TodoFx - Менеджер задач.

Это графическая программа для операционной системы Windows, которая помогает вести список ежедневных дел. Она создана с использованием графического движка ImGui и DirectX 11.

Ссылка на скачивание программы:
[Скачать TodoFx_Setup.exe (Версия v1.0.0)](https://github.com/isacks456/Todo/releases/download/v1.0.0/TodoFx_Setup.exe)

Возможности программы:
- Полное автоматическое сохранение изменений на жесткий диск при любом действии.
- Автоматическая загрузка сохраненного списка задач при каждом запуске приложения.
- Разделение задач по фильтрам: Показ всех дел, только в процессе или только выполненных.
- Умные кнопки фильтрации, которые автоматически блокируются и становятся серыми, если список задач полностью пуст.
- Кнопка одиночного удаления задачи и кнопка полной очистки всего списка со сбросом счетчика номеров.
- Кастомное темное оформление интерфейса.

Техническая часть:
- Язык программирования: C++
- Графика: Dear ImGui (Win32 и DirectX 11)
- Сборка проекта: CMake
- Создание установщика: Inno Setup
